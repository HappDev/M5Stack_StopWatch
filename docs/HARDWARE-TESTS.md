# Аппаратная проверка StopWatch

Эти действия выполняются на физическом устройстве с тестовыми аккаунтами. Автоматические тесты и успешная сборка не подтверждают аппаратную работоспособность.

| Проверка | Действие | Ожидаемый результат |
|---|---|---|
| Экран | Запустить прошивку | Круглый интерфейс без обрезанных кнопок; читаются кириллица, цифры, сообщения |
| Сенсор | Нарисовать и повторить ключ из 4–6 точек, прокрутить список | Нет пропусков, ложных нажатий и смещения координат |
| Кнопки | Нажать жёлтую, синюю, удержать синюю | Следующий аккаунт, список, блокировка. На экране входа синяя открывает отдельное меню сброса; при смене ключа отменяет ввод |
| Просыпание | Разблокировать, подождать 30 секунд, коснуться экрана или нажать кнопку | Экран гаснет, USB закрывается; до истечения 12 часов экран просыпается без повторного ввода ключа. После ручной блокировки нужен рисунок; касание пробуждения не выбирает точку |
| Повторный запрос ключа | После разблокировки проверить пробуждение до и после 12 часов; повторить с активным экраном, без USB и после изменения RTC | Через 12 часов требуется ключ, активность и установка часов не продлевают срок. Перезапуск и ручная блокировка требуют ключ сразу |
| Размер сетки и сброс | Нарисовать прежний ключ по крайним точкам, нажать синюю кнопку, открыть сброс и отменить | Сетка уменьшена на 20%, касания совпадают с точками; кнопка сброса находится на отдельном экране. Отмена сохраняет аккаунты |
| Индикатор ключа | Проверить правильный и неверный ключ, создание и смену; касаться экрана во время обработки | Кольцо вращается до результата; повторного запуска или случайного перехода нет |
| Список с кодами | Открыть тестовые 6/8-значные аккаунты с периодами 30/60 с, длинными названиями; прокрутить и дождаться смены кода | Имя/email слева, полный код справа; прокрутка сохраняется. Шестерёнка слева и замок справа работают, круглый экран не обрезает кнопки |
| Местные часы | Синхронизировать с компьютером, проверить переход через полночь и перезапуск; сменить пояс компьютера и повторить синхронизацию | Верхняя строка показывает местное время; настройка сохраняется. RTC и OTP сверяются по UTC; недостоверное RTC скрывает коды |
| Быстрое разрешение USB | Разблокировать с пустым списком, затем с аккаунтами и неустановленным временем | Кнопка «Разрешить USB» есть в списке, при неверном времени — также на экране кода. При корректном времени и наличии аккаунтов остаётся в настройках |
| USB | Подключить Chrome и отдельно Edge | CDC обнаруживается, команда status отвечает, неподтверждённый сеанс закрыт |
| Разрешение | Разблокировать и включить USB, вынуть кабель | При следующем подключении требуется новое физическое разрешение |
| Импорт | Добавить тестовый QR, URI и ручной Base32 | Верные названия и параметры; перед записью есть подтверждение |
| Пакетный импорт | С существующими тестовыми аккаунтами перенести несколько аккаунтов Google через сайт и JSON через CLI | Один запрос на весь набор с количеством добавлений и замен; прежние аккаунты сохранены, новые коды верны |
| Отмена пакета | Отменить общий запрос, затем повторить с обрывом USB во время передачи и до подтверждения | Хранилище не меняется; после нового разрешения USB набор можно передать заново |
| Сбой записи пакета | На тестовом хранилище прервать питание при сохранении подтверждённого набора | После перезапуска доступен старый или новый полный набор, частичного импорта нет |
| Подтверждение | Отклонить добавление/удаление/экспорт | Хранилище не меняется, секреты не передаются |
| Время | Установить время с задержкой подтверждения 20 секунд | После подтверждения RTC близок к времени ПК, а не отстаёт на 20 секунд |
| RTC | Выключить на час, включить и сравнить UTC | Время сохраняется; записать фактический уход часов |
| Потеря RTC | На тестовом устройстве вызвать VLF/потерю RTC-питания | Коды не показываются до установки времени |
| Коды | Сверить тестовые SHA1/SHA256/SHA512, 6/8 цифр, 30/60 секунд | Совпадают с независимым аутентификатором на нескольких интервалах |
| Графический ключ | Пять раз ошибиться и перезагрузиться | Сохраняется задержка; перезагрузка её не сокращает |
| Скорость проверки ключа | До и после обновления приложения измерить время от отпускания пальца до списка аккаунтов на одном тестовом хранилище; по пять правильных разблокировок | Прежний рисунок открывает те же аккаунты; записать медиану времени обеих версий. Отдельно проверить неверный рисунок и сохранение ограничителя попыток |
| Ёмкость | Восстановить набор из 100 записей | Все записи доступны и листаются; 101-я отклоняется |
| Копия | Экспорт, сброс, новый ключ, восстановление | Имена, секреты и коды восстановлены; ключ исходного устройства не нужен |
| Обрыв USB | Отключить при restore_item | Сохраняется прежний набор; повторный импорт начинается с нуля |
| Обрыв питания | Прервать сохранение тестового набора | После старта доступен старый или новый полный набор, частичного нет |
| Обновление | Выполнить app-flash с прежней таблицей разделов | Данные и графический ключ сохраняются |
| Отключённая сеть | Отключить интернет и повторить настройку | Сайт, QR, USB и копии продолжают работать |

## Bluetooth-клавиатура: аппаратный цикл

Статус: **не выполнен**; устройство для этого изменения не прошивалось. Выполнять с тестовыми аккаунтами, сначала в обычном текстовом редакторе, затем в браузере.

| Проверка | Действие | Ожидаемый результат |
|---|---|---|
| Первое включение | Обновить только приложение, открыть настройки Bluetooth | Аккаунты и рисунок сохранены; радио по умолчанию выключено |
| Сопряжение | Включить, открыть «Сопряжение», выбрать StopWatch OTP на ПК | На ПК и StopWatch одинаковое число из шести цифр; до физического подтверждения ввода нет |
| Отмена и срок | Отменить сравнение; отдельно ждать 60 секунд, в том числе после появления числа | Новое сопряжение не сохраняется; окно закрывается; экран не гаснет до окончания окна |
| Чужой компьютер | При сохранённом ПК попробовать добавить StopWatch на другом компьютере без удаления связи | Новое сопряжение и отправка не разрешаются; сохранённый ПК остаётся доверенным |
| Ввод из списка | Выбрать поле в редакторе, открыть карточку касанием строки | Одно точное число без Enter, Tab и очистки; проверить начальные нули, 6/8 цифр и повторяющиеся цифры |
| Повтор | Очистить поле, нажать на крупные цифры; быстро нажать ещё раз во время передачи | Один ввод; повторное нажатие во время отправки не добавляет второй код |
| Навигация | Переключать жёлтой кнопкой, прокручивать список, ждать смены TOTP, пробуждать экран | Ввода нет; после жёлтой кнопки касание крупного кода вводит код выбранного аккаунта |
| Граница периода | Нажать перед и после смены периода 30/60 секунд | Отправляются те же цифры, которые показывает карточка при начале передачи; обновление таймера не запускает ввод |
| Неверное время | На тестовом устройстве вызвать недостоверный RTC, открыть карточку и нажать код | Никакие цифры и заполнители не передаются; доступна синхронизация USB |
| Потеря связи | Отключить Bluetooth ПК до нажатия и отдельно посреди ввода | Отсутствует отложенный повтор; остаток отменён; после восстановления нужен новый клик, неполное поле очищается вручную |
| Сон и блокировка | Погасить экран на аккумуляторе, разбудить; заблокировать посреди передачи; проверить предел 12 часов | Связь сохраняется, первый жест только будит; блокировка отменяет ввод, истечение 12 часов требует рисунок |
| Перезапуск и удаление | Перезапустить обе стороны; затем «Забыть компьютер», перезапустить снова | Известный ПК переподключается без ввода кода; после удаления ключи не восстанавливаются, требуется новое сопряжение |
| Выключение и сброс | Выключить Bluetooth; отдельно подтвердить полный сброс на тестовом хранилище | Выключение сохраняется и возвращает прежний сон; полный сброс удаляет аккаунты и сопряжение, радио выключено |
| USB вместе с Bluetooth | С подключённой клавиатурой установить время, добавить аккаунт, экспортировать копию | Сохраняется физическое подтверждение; USB и Bluetooth работают, сохранение данных не срывает связь |
| ОС и раскладки | Повторить редактор и браузер в Windows/macOS с русской/английской раскладками | Точные цифры в активном поле; для Parallels отдельно проверить фокус окна гостевой ОС |
| Питание | Измерить ток с погашенным экраном при Bluetooth on/off и после блокировки | Записать реальные результаты; автономность не оценивать по симуляции |

## Графический ключ: дополнительный аппаратный цикл

Статус: **не выполнен** для этого изменения; устройство автоматически не прошивалось.

- Проверить ключи из 4, 5 и 6 точек, подсветку и линии внутри круглого экрана; повторить медленно и быстрым движением.
- Проверить 3 и 7 точек: весь ввод отклоняется, устройство не разблокируется; повторное прохождение выбранной точки не удлиняет рисунок.
- Соединить крайние точки ряда, столбца и диагонали: промежуточная добавляется автоматически. Уже выбранная середина повторно не добавляется.
- Отпустить палец вне сетки, вызвать потерю касания, отменить ввод и заблокировать боковой кнопкой: незавершённый рисунок не сохраняется.
- Создать ключ, ошибиться при повторе, сменить ключ и отменить смену. После перезагрузки подходит только успешно сохранённый ключ.
- На тестовом хранилище формата 1 ввести прежний PIN. До двукратного задания рисунка боковые кнопки и USB не открывают аккаунты; отмена снова требует PIN. После перехода все аккаунты и коды сохранены.
- Прервать питание на разных этапах миграции и смены ключа. Экран запрашивает способ входа последнего подтверждённого снимка, аккаунты сохранены.
- Проверить таймер после пяти неверных рисунков и перезагрузки. Во время задержки новые точки не выбираются.
- Проверить пробуждение касанием и обеими боковыми кнопками: первоначальный жест только пробуждает экран.

## Измерение аккумулятора

Используйте измеритель тока на линии аккумулятора с учётом версии платы и её схемы. Никакой разборки для обычной настройки не требуется. У StopWatch v1.0 контакт с ошибочной надписью BAT может быть входом 5V; перед любым подключением измерительных проводов проверьте [версию и схему M5Stack](https://docs.m5stack.com/en/core/StopWatch).

Измерьте и запишите: напряжение аккумулятора перед тестом, средний ток при экране с кодом, средний ток после блокировки и сна, ток при USB-сеансе, время работы за сутки с заданным числом пробуждений. Отдельно проверьте удержание часов после штатного выключения и после полного разряда. Расчёт по номинальным 450 мА·ч не заменяет измерение.

Фактическое время работы и длительность KDF пока не заявлены: их нужно измерить на устройстве.

## Восстановление при ошибке NVS

Если повреждён счётчик NVS, штатная прошивка закрывает доступ и не форматирует его автоматически. При наличии резервной копии выполните явное восстановление: переведите устройство в загрузчик, сотрите область NVS `0x9000…0xEFFF` командой esptool `erase-region 0x9000 0x6000`, перезагрузите, подтвердите сброс обоих разделов хранилища на экране, создайте графический ключ и восстановите `.otpvault`. Это удаляет штатное состояние ограничителя попыток и требует последующего сброса хранилища; используйте процедуру только для восстановления собственного устройства. eFuse не меняется.

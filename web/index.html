01СКАЧАЙТЕ ФАЙЛ

Скачайте прошивку

Сохраните готовый образ StopWatch OTP для первой установки на ваше устройство.

Скачать прошивку ↓stopwatch-otp.factory.bin · ESP32-S3
02УСТАНОВИТЕ ПО USB

Прошейте StopWatch

Подключите устройство. В ESPHome Web нажмите Connect → Install и выберите скачанный файл.

Открыть ESPHome Web ↗Откроется в новой вкладке
03НАСТРОЙТЕ УСТРОЙСТВО

Создайте графический ключ

Перезапустите StopWatch и задайте ключ из 4–6 точек на его экране. Закройте соединение в ESPHome Web и вернитесь сюда.

Перейти к настройке ↓Дальше — подключение и аккаунты
НА ЗАМЕТКУ

В Install выбирайте скачанный файл. Prepare for first use устанавливает другую прошивку. Если браузер открыт на Mac, передайте USB-устройство macOS, а не Windows в Parallels.

Этот образ — для первой установки. Для обновления с сохранением аккаунтов используйте инструкцию из полного комплекта.

ПОСЛЕ УСТАНОВКИ

Как добавить аккаунт

01ПОДКЛЮЧЕНИЕ

Разрешите доступ

Выберите USB-порт, разблокируйте StopWatch графическим ключом и разрешите USB в настройках устройства.

02ДОБАВЛЕНИЕ

Добавьте аккаунт

Загрузите QR-картинку из настроек 2FA сервиса или вставьте его секрет. Для переноса используйте «Из Google Authenticator».

03ПОДТВЕРЖДЕНИЕ

Подтвердите на экране

Проверьте данные на StopWatch и подтвердите сохранение. После добавления создайте новую резервную копию.

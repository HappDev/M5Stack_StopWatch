02 / УСТАНОВИТЕ ПО USB

Откройте ESPHome Web

Подключите StopWatch. На открывшемся сайте нажмите Connect → Install и выберите скачанный файл.

Прошить в ESPHome Web ↗Откроется официальный сайт по HTTPS

Выбирайте свой файл в Install. Кнопка Prepare for first use устанавливает другую прошивку. Если браузер открыт на Mac, передайте USB-устройство macOS, а не Windows в Parallels.

Этот образ — для первой установки. Для обновления с сохранением аккаунтов используйте инструкцию из полного комплекта.

Комплект и настройка после прошивки

Скачайте и распакуйте комплект с прошивкой и инструкцией. Первая установка выполняется через ESPHome Web по кнопке выше. Для настройки аккаунтов по USB запустите сайт на компьютере с браузером: на Windows — start-web.cmd, на Mac — python3 tools/server.py из папки проекта. Затем откройте http://127.0.0.1:8765/ в Chrome или Edge. В комплекте также есть инструкция настройки HTTPS.

Секреты обрабатываются в памяти этого браузера при импорте и копировании.
